# W031 — Capability Reproduction Factory

## Dependency
W028 + W029 + W030.

## Owned surfaces
- packages/epoch-capability-reproduction/**
- qa/epoch-capability-reproduction/**

## Goal
Build the governed pipeline that turns a missing/inadequate external software capability into an Epoch mini-app when reproduction is necessary and rights/quality gates permit it.

## Deliverables
- intake and bounded-scope process;
- native/open-source/standard/license alternatives analysis;
- rights/provenance gate and blocked state;
- reference behavior contract and approved case capture;
- foundation selection and dependency/license inventory;
- mini-app build/package lifecycle;
- shared human UI and typed agent-visible state/actions;
- W030 benchmark execution;
- version, limits, security evidence and rollback metadata.

## Acceptance
- One bounded capability completes the full pipeline.
- Implementation-internal inspection/decompilation is inaccessible until specific authorization and review are attached.
- Protected source/assets/datasets/branding are not copied without required rights.
- Result opens through the generic Epoch workbench surface; it is not merely an MCP wrapper.
- Release is impossible when rights, quality, security, safety, license or provenance gates fail.

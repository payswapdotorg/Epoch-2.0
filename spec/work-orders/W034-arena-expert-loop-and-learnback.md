# W034 — Arena expert loop and learnback

## Dependency
W025 + W029 + W032.

## Owned surfaces
- packages/epoch-arena-adapter/**
- qa/epoch-arena-adapter/**

## Goal
Complete the structured return loop so a gap is scoped for a qualified Arena expert, resolved with project context, verified on return and considered for permissioned capability reuse.

## Deliverables
- expert task package and minimized/redacted evidence export;
- qualification/scope/budget/deadline/acceptance metadata;
- typed return/deliverable package;
- verification and world-revision proposal;
- partial/rejected result handling;
- independent reuse-rights decision;
- linkage to learning and demonstration pipelines.

## Acceptance
- Simulated expert endpoint proves full round trip before production procurement.
- Expert output is not assumed correct solely because it came from an expert.
- Accepted results flow through canonical world/verification authority.
- Confidentiality and reuse permissions are enforced independently.
- Reusable capability is a separate evaluated artifact, not an automatic consequence of delivery.

# Task-Conditioned Reconstruction Acceptance

1. Early feasibility from photos/approximate dimensions returns broad ranges and explicit unknowns without requiring full structural-grade detail.
2. BOQ requires measurable quantities and traceable assembly/rate assumptions beyond the feasibility profile.
3. Clash checks report relevant systems, tolerances and coverage; unchecked systems are not implied to be validated.
4. Structural analysis blocks when mandatory loads, supports, properties or code inputs are missing, unless explicitly marked exploratory and bounded.
5. Conflicting drawing/photo/site evidence retains source and timestamp and causes reconciliation or conditional results.
6. A new work-type profile can be registered without a second world or renderer-specific profile logic.
7. When the task changes, Epoch recalculates sufficiency and asks only for potentially decision-changing evidence.
8. Agents cannot silently promote inferred/default geometry to confirmed facts.

Evidence includes selected profile, sufficiency state, uncertainties, user requests and world revision lineage.

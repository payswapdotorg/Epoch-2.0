# Capability Reproduction Factory Acceptance

1. The factory demonstrates why native embedding, supported integration and suitable open/standard/licensed foundations are inadequate before choosing reproduction.
2. A reference request with unclear rights blocks implementation-internal analysis pending review.
3. An approved reference request records permitted methods, sources and provenance.
4. The factory scopes a capability slice rather than automatically cloning the reference product.
5. The resulting mini-app opens inside the Epoch workbench through the generic surface, like Browser/Terminal.
6. Both human UI operation and agent use of structured state/actions work under the same permission policy.
7. Reference cases, edge cases, failures/recovery, performance and security checks run.
8. Release includes version, benchmark report, dependency/license inventory, limitations, compatibility and rollback.
9. A deliberately failed rights or quality gate prevents release.
10. Reference-version drift causes a visible requalification/regression result.

No “top-tier”, “equivalent” or “reference-superior” claim may ship without an explicit task suite and evidence.

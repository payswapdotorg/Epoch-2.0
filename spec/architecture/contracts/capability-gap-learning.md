# Capability Gap Learning Contract

## Purpose

Epoch reduces repeated human intervention by turning verified experience into validated capabilities. Learning can mean better reconstruction, tool adapters, semantic bindings, skills, workflows, tests, agent specialization or—when justified—model adaptation. A captured event does not automatically train a foundation model.

## Gap record

Record project/task/world revision, blocked objective and acceptance criteria, failure evidence, classification/confidence, attempts/tools/environments/results, consequences of error, missing information/tool access/skill/reasoning/authorization/expertise, remediation proposal and permission scope.

## Classify before routing

Possible classes include incomplete or conflicting evidence; inadequate environment observation/control; missing native capability; reusable skill gap; reasoning/model limit; authority/approval requirement; professional judgment/certification; user's unavailable expertise/time; or infeasible/conflicting constraints.

Fix the correct layer: ask for a missing measurement when that is enough; improve an adapter when the agent cannot observe/control; create a capability when a validated repeatable workflow is missing; escalate to a qualified expert when judgment remains unavailable.

## Lifecycle

1. Detect and preserve the gap.
2. Triage evidence, risk and likely cause.
3. Request information, use another capability, retry safely, capture a human demonstration, commission reproduction, or escalate to Arena.
4. Extract a bounded candidate skill/workflow/adapter/rule/test only with permission.
5. Validate on the original case and representative held-out cases.
6. Review rights, privacy, engineering safety, permissions and generalization limits.
7. Publish a versioned candidate, or keep it project-local/rejected.
8. Monitor regressions and roll back when necessary.

## Reuse permissions

- PROJECT_LOCAL: originating project only.
- ORGANIZATION_SHARED: explicitly approved for a named tenant/organization.
- COMMUNITY_PUBLIC: rights/privacy reviewed and explicitly released.
- GENERAL_MODEL_TRAINING: a separately governed opt-in, never implied by use or environment attachment.

A human demonstration or expert result never automatically grants autonomous execution authority. Each capability lists preconditions, allowed operations, expected outputs, failure handling, supported cases, confidence bounds, human-review requirements and rollback.

## Success measure

A representative task requires fewer interventions and/or lower total cost/time while maintaining or improving verified quality and safety. Intervention reduction alone is not success.

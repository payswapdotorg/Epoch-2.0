# Arena Expert Escalation and Return Contract

## Purpose

Arena is Epoch's channel for sourcing qualified human expertise when the user and current agents cannot close a capability gap. Epoch owns the project's end-to-end world and evidence; Arena owns expert procurement/execution. Neither is a second semantic-world authority.

## Escalation trigger

Escalate when information requests, permissioned retries, existing registered capabilities and environment fixes are insufficient, and the task requires expert judgment or capability. Safety-critical, licensed or regulated decisions require the qualification and review applicable to the task regardless of agent confidence.

## Expert task package

Include only authorized and necessary context: objective and acceptance criteria; current world revision/digest and relevant variants; reconstruction profile/fitness state; evidence with sources/time/rights; constraints, units and jurisdiction; prior attempts and failures; open questions, uncertainties and assumptions; scoped/redacted environment traces; deliverables and validation criteria; budget/deadline/confidentiality; and explicit reuse permissions.

Experts should not have to reconstruct known authorized context from unstructured chat.

## Return package

Include authored artifacts and formats, decisions/calculations/recommendations, assumptions and limits, evidence/references/input/tool versions, verifiable claims, validation results, unresolved items, required approvals, qualification information where applicable, and IP/confidentiality/reuse permissions. Provide machine-readable changes as well as a human explanation where feasible.

## Acceptance and incorporation

Expert output is external, provenance-bearing input. Validate against the requested profile and acceptance suite; resolve conflicts with current world; create a proposal/new revision rather than silently overwriting approved state. Reject/partially accept with reasons. A reusable skill or capability is a separate rights-controlled evaluation step, never an automatic result of expert delivery.

## Privacy and success

Use least-privilege evidence, tenant isolation, redaction, confidentiality and retention limits. A successful loop preserves context from escalation through verified return; it does not imply global reuse of deliverables.
